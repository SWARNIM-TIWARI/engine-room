# Security Policy

Engine Room is a static front end. It has no backend, no accounts and no user data. The only outside request it makes is to the public Wikipedia API.

## Reporting a vulnerability

If you find something, please do not post it in a public issue. Use GitHub's private vulnerability reporting on the Security tab of this repository, or message [Swarnim on LinkedIn](https://www.linkedin.com/in/swarnimtiwari1).

You can expect a reply within a few days.

## Supported versions

Only the latest version on the `main` branch is maintained.
