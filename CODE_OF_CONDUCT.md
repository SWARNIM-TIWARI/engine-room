# Code of Conduct

This is a small project about learning. Keep it a place where people can ask basic questions and point out mistakes without feeling stupid.

## What that looks like

- Be kind and assume good faith.
- Criticize the work, not the person.
- Corrections are welcome. Say what is wrong and, if you can, link a source.
- Beginners are welcome. Nobody needs to prove they already know the topic.

## What is not okay

- Harassment, insults or personal attacks
- Discriminatory language or jokes
- Spam or self promotion unrelated to the project
- Sharing someone's private information

## Enforcement

Maintainers can edit, hide or delete comments, issues and pull requests that break these rules, and can block repeat offenders.

To report a problem, message [Swarnim on LinkedIn](https://www.linkedin.com/in/swarnimtiwari1) or open an issue without sensitive details and ask for a private channel.

This is a short plain language version inspired by the Contributor Covenant.
